# B100-Github
A review of what Github is and how you can retrieve starter code for assignments.

## Github Classroom vs Github
In previous years, we have made use of Github Classroom to do "1 click" retrieval of starter code for assignments.  The Github Classroom project has been abandoned, but we can still make use of Github to create our starter code by cloning existing Github Repositories.  There are several pros and cons of Github over Github Classroom:

## Differences
* You will have greater control over your own repository
* You will need to clone the repository on your own.  Theoretically, you could also fork it or create a pull request.
* You will need to make your repository public or add your teacher as a collaborator to share your code with them.

## Assignment
* try each of the following to see what you can/cannot do.

1. Open up the repository at https://github.com/sdcst12/B100-Github and look for the green CODE button. You should be able to use this to clone the repository.  This will be the "Open with Github Desktop" option.
2. Make some changes to a file and try to commit them back.  When you try to, you will get a warning page to contact the adminstrator and will be able to create a fork of the repository.
3. Ask a search engine or AI what is meant by "forking a repository".  At the prompt, ask any questions you feel you need to in order to get a good understanding of what is going on and include it in your assignment sheet.

4. Ask the AI what is the difference between forking a repository and creating a pull request.  Again, ask enough questions/prompts that you can explain the difference and include it on your answer sheet.
